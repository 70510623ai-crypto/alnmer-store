# متجر مطبعة النمر — ALNMER CMYK STORE

متجر مستقل جديد بهوية CMYK وشعار ALNMER الأصلي، مع خدمة الطلب وفق القياسات وإرسال الطلب عبر WhatsApp، ولوحة تحكم تتابع الطلبات والخدمات والأسعار.

## الملفات

- `public/index.html` المتجر الذي يراه الزبون
- `public/admin.html` لوحة تحكم الإدارة
- `public/assets/alnmer-logo.png` الشعار الأصلي المرفق
- `netlify/functions/catalog.mjs` إدارة قائمة الخدمات
- `netlify/functions/orders.mjs` استقبال الطلبات وتعديل حالاتها
- `netlify.toml` ضبط الموقع ووظائف Netlify

## النشر الفعلي (الأفضل على Netlify)

1. فك الضغط عن المشروع وارفع محتوياته إلى مستودع GitHub **جديد**. لا ترفع الملفات داخل موقعك القديم إلا إذا أردت استبداله.
2. من Netlify اختر **Add new project → Import an existing project** واختر المستودع الجديد.
3. اختر أمر البناء `npm run build` ومجلد النشر `public`؛ يقرأ Netlify هذه القيم من `netlify.toml` تلقائياً.
4. ضمن **Project configuration → Environment variables** أضف `ADMIN_PASSWORD`، واستعمل **كلمة مرور قوية وفريدة لا تقل عن 12 حرفاً**. لا تضع الكلمة في ملفات المشروع أو JavaScript.
5. أعد النشر بعد إضافة متغير البيئة. افتح رابط المشروع الجديد للمتجر، و`/admin.html` للوحة التحكم.
6. الطلبات والخدمات محفوظة في **Netlify Blobs** ضمن الموقع نفسه؛ ستظل موجودة بعد تحديث الموقع. يمكنك تغيير الأسعار والخدمات من لوحة التحكم بعد تسجيل الدخول.
7. اجعل المشروع منشوراً على HTTPS (يوفر Netlify رابط HTTPS تلقائياً). الأفضل ضبط حماية إضافية ضد الرسائل الآلية قبل نشر المتجر على نطاق واسع، وأخذ نسخ احتياطية دورية من الطلبات.

## اختبار محلي

يحتاج Node.js الحديث وNetlify CLI. شغّل:

```bash
npm install
npx netlify dev
```

افتح العنوان الذي سيظهر في الطرفية. صفحة `index.html` عند فتحها مباشرة بدون Netlify تعرض المنتجات الافتراضية وتجهّز رسالة واتساب، لكن **لا تحفظ الطلبات مركزياً**. لوحة التحكم تحتاج تشغيل وظائف Netlify وإضافة كلمة مرور البيئة.

## طريقة عمل الطلب

- الزبون يختار الخدمة، القياس **بالسنتيمتر** والكمية والخامة والملاحظات، ثم يملأ الاسم والهاتف.
- عند وجود الخادم يتم حفظ الطلب أولاً، وبعدها يُفتح واتساب برقم **+961 70 510 623** مع كل التفاصيل. **الزبون لازم يضغط إرسال في واتساب** لكي تصلك الرسالة.
- إن لم يعمل الخادم، يمكن إرسال الرسالة عبر واتساب كحل بديل، لكن **لن يُحفظ الطلب في لوحة التحكم**.
- تُحسب الأسعار التقديرية فقط للخدمات التي تحدد سعرها أنت من لوحة التحكم. السعر النهائي يخضع لتأكيد المطبعة.
- لا توجد بوابة دفع إلكتروني أو رفع ملفات فعلي في هذا الإصدار. يرسل الزبون صورة/ملف التصميم بنفسه داخل محادثة واتساب.

## حماية وخصوصية

- صفحة الإدارة لا تكشف الطلبات بدون كلمة مرور الخادم؛ التحقق يتم داخل Netlify Functions.
- البيانات الشخصية للزبائن تُحفظ ضمن Netlify Blobs. احرص على تأمين الحساب وعدم مشاركة كلمة مرور الإدارة.
- يلزم إضافة حماية spam/rate limiting، وسياسة خصوصية مناسبة قبل استخدام الموقع بشكل موسّع.

## تحديث 2 — إضافة الصور للخدمات

من لوحة التحكم `/admin.html`، افتح **الخدمات والأسعار** ثم **تعديل** أو **إضافة خدمة**. ضمن **صورة الخدمة** اضغط «اختر صورة من الكمبيوتر»، واختر JPG أو PNG أو WebP. انتظر رسالة «الصورة جاهزة»، ثم اضغط **حفظ الخدمة**. ستظهر الصورة على صفحة الزبائن مباشرة بعد تحديث الصفحة.

- تُضغط الصور داخل المتصفح وتحول إلى WebP، ثم تُخزن في Netlify Blobs (`alnmer-product-images`) بشكل دائم عبر وظيفة `netlify/functions/media.mjs`.
- إن لم تضف صورة يبقى الرسم التوضيحي السابق. بإمكانك إزالة الصورة من نموذج التعديل، ثم حفظ الخدمة.
- لا تُحذف الصور القديمة من التخزين تلقائياً عند الاستبدال، لتجنب فقدان أي روابط قيد الاستخدام؛ راقب سعة التخزين.
- رفْع الصور محمي بكلمة مرور لوحة التحكم على الخادم، لكن **مشاهدة الصور عامة للزبائن**.
- المستودع القديم يمكن تحديثه **بدون إنشاء مشروع Netlify جديد**: ارفع ملفات هذا الإصدار إلى نفس مستودع `alnmer-store` على GitHub، ثم اضغط Commit changes. سيُنشر التحديث تلقائياً على نفس رابط الموقع. لن تتأثر الطلبات والأسعار المحفوظة في Netlify Blobs.
- احتفظ بنسخة احتياطية من بيانات الطلبات والخدمات قبل تغييرات كبيرة.

## التحديث 3 — التصميم الفخم + الخدمات الجديدة + الدليفري

هذا الإصدار يستبدل تصميم واجهة المتجر (ألوان CMYK والشعار الأصلي)، ويضيف:
- صور هوية وباسبور **دون أي ادعاء أنها جاهزة خلال 5 دقائق**، وخيار التصوير في المطبعة أو إرسال صورة جاهزة عبر واتساب.
- طباعة ملفات PDF مع اختيار أبيض وأسود أو ملوّن، حجم الورق، وجه أو وجهين، وعدد الصفحات والنسخ.
- تظهير وطباعة الصور بمقاسات 10×15 و13×18 و15×21 وA4 وتشطيب لامع أو مطفي.
- فك وتركيب القارمات مع نوع الخدمة ومنطقة العمل والقياسات.
- خيار **استلام من المطبعة** أو **دليفري** عند إتمام الطلب. عند اختيار الدليفري يلزم عنوان، ويوضح المتجر ورسالة واتساب أن **سعر الدليفري حسب الطلب**، بدون تحديد أي مبلغ ثابت.
- الخدمات الأربعة الجديدة تضاف تلقائياً لمتجر Netlify الموجود عند أول قراءة للكتالوج بعد التحديث، مع الحفاظ على الخدمات والأسعار والصور السابقة. لا يُعاد تكرار الإضافة في التحديثات اللاحقة.
- صور الخدمات ما زالت قابلة للرفع من لوحة التحكم كما في الإصدار السابق.

### تحديث الموقع الموجود **alnmer-sign-design.netlify.app**

1. **لا تنشئ مشروعاً جديداً على Netlify** ولا تغيّر إعداد ADMIN_PASSWORD.
2. افتح مستودع GitHub الذي ربطته مسبقاً مع المتجر `alnmer-store`.
3. ارفع **كل محتويات هذا المجلد** إلى الجذر، مع المجلدين `public` و`netlify`، واستبدل الملفات التي تتطابق أسماؤها (لا ترفع ملف ZIP مباشرة ولا تضع المشروع داخل مجلد إضافي).
4. اضغط Commit changes على الفرع `main`؛ Netlify سيعيد النشر تلقائياً.
5. تأكد من Published، ثم افتح المتجر وجرب خدمة طباعة PDF واختيار الدليفري وإرسال الطلب عبر واتساب.
6. لوحة التحكم لا تزال في `/admin.html` بنفس كلمة المرور؛ الطلبات والكتالوج المخزنان في Netlify Blobs يحتفظان بالبيانات الحالية.

**ملاحظة:** ملفات الصور/PDF التي يريد الزبون طباعتها **لا تُرفع من متجر الزبون إلى الخادم**؛ بعد فتح واتساب على الرقم +96170510623 يرسلها الزبون بنفسه داخل المحادثة. **ولا يكفي فتح واتساب لإرسال الطلب؛ يجب أن يضغط الزبون إرسال**. وفي حال تعذّر حفظ الطلب على الخادم، سيظل واتساب خياراً احتياطياً لكن الطلب قد لا يظهر في لوحة التحكم.
